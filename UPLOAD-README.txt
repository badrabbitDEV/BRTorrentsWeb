BRTorrentsWeb - frontend separado

Este pacote contém somente apps/web do repositório original, na raiz.
O backend (api/engine), banco e arquivos .env não foram incluídos.

Antes de publicar: configure a URL pública real da API no meta brt-api-base
no index.html. Não coloque senhas, tokens administrativos ou credenciais
qBittorrent no frontend.

GitHub Pages: em Settings > Pages, selecione GitHub Actions.
O vite.config.js está configurado para o repositório BRTorrentsWeb.
